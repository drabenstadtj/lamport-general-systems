# LGS Playtest

### Things to note

- core loop timing
- first robot interaction
- first successful hack
- repair/destroy choice

### Watch For

| Area                                              | Y/N | Notes |
| ------------------------------------------------- | --- | ----- |
| Player observes before acting                     |     |       |
| Player reads logs/docs voluntarily                |     |       |
| Player understands what each terminal command did |     |       |
| Player predicts network response                  |     |       |
| Player notices network reacting to their actions  |     |       |
| Player mixes terminal + physical approaches\*     |     |       |
| First robot encounter lands                       |     |       |
| Detection feels fair                              |     |       |
| Player triggers consensus (how/when?)             |     |       |
| Player gets stuck (where?)                        |     |       |
| "Aha" moment happens (what?)                      |     |       |

\*physical = power buttons, avoiding robot. terminal = crash/corrupt/block/spoof/consensus

## Player Survey

1. What were you trying to do most of the time?

2. How well did you understand the node states (healthy / crashed / byzantine)? **(1=lost, 5=got it)**

3. Was there a moment the network made sense to you? What caused it?

4. What part of the network was most confusing?

5. How did the terminal feel? **(1=frustrating, 5=satisfying)**

6. What was your approach?

7. Did you feel like you had a choce in how to handle problems? **(1=one right answer, 5=many options)**

8. Did you notice the network reacting to your actions? **(Yes / Vaguely / No)**

9. When detected, did you understand why? **(1=never, 5=always)**

10. Pacing? **Too slow / Right / Too fast**

11. Difficulty? **Too easy / Right / Too hard**

12. Did you know you could run consensus to open the door? **Yes / Eventually / No**

13. Was it clear that crashing vs corrupting a node did different things? **(1=no difference, 5=totally clear)**

14. Was the repair/destroy choice clear? **Yes / Mostly / No**

15. Did it feel like it mattered? **(1=didn't care, 5=felt heavy)**

16. Best moment?

17. Most frustrating moment?

18. One thing you'd change?

19. Would you keep playing? **Yes / Probably / No**
